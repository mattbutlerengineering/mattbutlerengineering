# CLAUDE.md - Marketing Site Conventions

## Domain Context
Public marketing site for mattbutlerengineering.com.
Built with React, Vite, and Rialto design system.

## Project-specific rules
- Use `apps/marketing/src/components` for local components.
- Use `packages/rialto` for shared UI components.
- Follow mobile-first responsive design.

## Commands
- `pnpm dev` - Start dev server
- `pnpm build` - Build for production
- `pnpm lint` - Run linting
- `pnpm typecheck` - Run type checks
