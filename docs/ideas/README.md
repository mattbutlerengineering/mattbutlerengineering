# Big ideas

One file per week (`YYYY-MM-DD.md`), written by the scheduled `mbe-big-ideas` routine: bold, 3-to-5-year bets for the hospitality product, not sprint-sized features.
These files are for a human to read. Nothing here is filed as an issue or labelled `ready`.
To promote an idea, run the `/idea` skill on it; that starts the normal idea → PRD → decompose pipeline.
Do not edit old entries. A later week may evolve an earlier idea, and must say which entry it extends.
