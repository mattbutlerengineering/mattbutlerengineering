## Framework Comparison

### 1. Playwright (Current — Recommended)

Microsoft's E2E testing framework. Open source (Apache 2.0).

| Criterion | Details |
|-----------|---------|
| **Browsers** | Chromium, Firefox, WebKit (Safari) — all three with one API |
| **Languages** | TypeScript/JavaScript, Python, Java, .NET |
| **TypeScript** | First-class — written in TypeScript |
| **Parallelism** | Built-in — 15-30 concurrent tests per 8-core machine via browser contexts |
| **Speed** | Fastest E2E framework (14 min vs 90 min Cypress for same suite in benchmarks) |
| **Auto-waiting** | Built-in — waits for elements to be actionable before interacting |
| **API testing** | `request` fixture for HTTP API testing alongside browser tests |
| **Visual regression** | Built-in screenshot comparison |
| **Trace viewer** | Built-in trace recording and viewer for debugging |
| **CI integration** | First-class GitHub Actions support |
| **Cost** | $0 (open source) |

**Key strength:** Already in the project, already configured, and objectively the best E2E framework in 2026 on performance, browser coverage, and TypeScript support.

---

### 2. Cypress

The original developer-friendly E2E framework. Founded 2014.

| Criterion | Details |
|-----------|---------|
| **Browsers** | Chrome, Edge, Firefox (no Safari/WebKit) |
| **Languages** | JavaScript/TypeScript only |
| **Parallelism** | Paid (Cypress Cloud) — $67/month for 3 parallel runs |
| **Speed** | 3-6x slower than Playwright in benchmarks |
| **Auto-waiting** | Built-in |
| **Developer experience** | Excellent GUI test runner; best visual debugging |
| **Visual regression** | Plugin-based (Percy, Applitools) |
| **Cost** | Open source (MIT) + paid cloud ($67-279/month for parallelism and dashboard) |

**Key strength:** The interactive test runner GUI is the best in the industry for debugging tests visually. If you're writing E2E tests daily and need a visual debugging workflow, Cypress is excellent.

**Elimination reason:** Already using Playwright. Switching would lose WebKit/Safari testing, built-in parallelism (free), and visual regression. Cypress's interactive GUI is nice but not worth the migration cost and feature regression. Paid parallelism ($67+/month) vs Playwright's free parallelism is the clincher.

---

## Recommendation: Stay on Playwright

**Playwright is the correct choice. No change needed.**

The project already has Playwright installed and configured. The framework is the fastest, has the broadest browser coverage, and is free including parallelism.

**Improvement opportunities:**

| Action | Effort | Impact |
|--------|--------|--------|
| Add E2E tests for critical booking flow | 4-8 hours | Catch regressions in the primary user journey |
| Add visual regression tests to CI | 1-2 hours | Automated design system consistency checks |
| Configure Playwright for dashboard app | 2-4 hours | E2E coverage of authenticated dashboard flows |
