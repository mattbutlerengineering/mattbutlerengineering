# Revert RCA Loop

Files a Root Cause Analysis task when a merged PR has been reverted. All logic lives in `scripts/revert-rca.mjs`; this skill is only the manual entry point.

## Usage

```bash
node scripts/revert-rca.mjs --pr <N>   # N = the ORIGINAL (reverted) PR number
```

The script independently re-derives the merged revert PR and sha for `<N>` (never trusting a caller-supplied sha, #3583), classifies the original PR as agent-authored by label (`has-pr`), bot author, or branch prefix (`agent-`, `worktree-agent-`), de-duplicates against an existing RCA issue, and files the RCA issue. Reflections land in `.claude/reflections/RCA-PR-<N>.md`. Needs `GITHUB_TOKEN` and a built `@mbe/gh-client` (`pnpm build --filter @mbe/gh-client...`).

## What covers what

| Path                                    | Trigger                                 | Covers                                                                                                         |
| --------------------------------------- | --------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `.github/workflows/revert-watchdog.yml` | push to main breaks CI                  | Opens the revert PR titled `revert: #N (fixes broken main)` plus a broken-main issue; files no RCA itself.     |
| `.github/workflows/revert-rca-loop.yml` | PR merged with title starting `revert:` | Runs `revert-rca.mjs --pr N` for the watchdog's PRs and hand-titled `revert: #N ...` PRs (#5960 -> RCA #5969). |
| This skill (manual)                     | `/revert-rca-loop <N>`                  | Re-running the script for a `revert: #N` PR whose workflow run failed or was skipped.                          |

The PR _title_ is what both the workflow and the script match (`revert:` prefix, `#N` in the title); the squash commit subject (`Revert "..." (#5960)`) is irrelevant. GitHub's default `Revert "..."` PR titles from the UI button match neither, so such a revert gets no RCA until the PR is retitled `revert: #N ...`. The script files an RCA for non-agent PRs too (the agent check only logs).

The retired `revert-rca-detection.yml` (hourly, gated on a `Generated by @mbe/agent-core` PR-body marker nobody emits, case-sensitive `^Revert` grep) covered nothing and was removed.

## Next steps after an RCA

1. Fix the root cause or file a follow-up issue if systemic.
2. Add the pattern to `.claude/rules/gotchas.md` or the relevant skill.
3. Add a regression test.
