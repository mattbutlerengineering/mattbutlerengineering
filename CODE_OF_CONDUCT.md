# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1, as its code of conduct. The full text is canonical and stable at:

> **https://www.contributor-covenant.org/version/2/1/code_of_conduct/**

By participating in this project — opening issues, submitting pull requests, posting in Discussions, or interacting in any other project space — you agree to abide by it.

## Scope

The Code applies to all project spaces:

- This GitHub repository (issues, pull requests, Discussions, code review comments).
- Any maintainer-run venue (community calls, chat channels, project subdomains).
- Public spaces when an individual is officially representing the project.

It also applies in interactions where the connection to the project is reasonably clear, even outside the venues above.

## Reporting

To report a violation, use one of these channels:

1. **GitHub Security Advisory** (private to maintainers) — https://github.com/mattbutlerengineering/mattbutlerengineering/security/advisories/new — preferred for sensitive reports involving public figures, harassment, or potential legal issues.
2. **Email** — `conduct@mattbutlerengineering.com` — forwards to the maintainer's inbox; replies are signed.

Please include: what happened, where (link to issue/PR/comment if public), who was involved, and what outcome you'd like.

We acknowledge reports within 72 hours. We follow the [Contributor Covenant Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) — Correction → Warning → Temporary Ban → Permanent Ban — at the maintainer's discretion based on severity and pattern. The reporter is updated on the resolution unless they request anonymity from the offender.

## Enforcement contact

Maintainer: **Matt Butler** (`@mattbutlerengineering` on GitHub).

The maintainer may recuse from enforcement decisions involving conflicts of interest and delegate to a neutral third party in those cases.
