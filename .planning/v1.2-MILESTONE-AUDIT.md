### Integration Gaps

1. **GenCopilot local dev proxy** — `apps/hospitality/vite.config.ts` proxies `/api` to port 3004 (reservations). GenCopilot's `/api/gen/ui` needs port 3003 (agent). Fix: add `/api/gen` proxy rule before `/api` catch-all. Production unaffected. (COP-01, COP-02, COP-03)

2. **Stream format compatibility** — `toUIMessageStream()` + `Output.object` may produce prefix-coded SSE lines that `useGenStream`'s `JSON.parse` cannot handle. Needs production validation with live streaming request. (GEN-01, PLAY-03, COP-01, PERS-05)

3. **INFRA-02 Pulumi resource** — Gen Worker is deployed via wrangler in CI, not managed by Pulumi. The requirement as written asks for a Pulumi resource. The GEN Service Binding in Pulumi references the wrangler-deployed Worker.
