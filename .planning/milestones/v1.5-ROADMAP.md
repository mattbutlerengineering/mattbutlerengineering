# Roadmap: Milestone v1.5 - Repository Health & Polish

**Milestone Goal:** Clean up configuration technical debt and improve the visual presentation/status of the repository for developers.

## Phases

### Phase 41: Configuration Consolidation (Lighthouse)
**Goal**: Remove duplicate Lighthouse configuration files and ensure the primary configuration is correctly referenced.
**Success Criteria**:
  1. `lighthouserc.json` is deleted.
  2. `lighthouserc.js` is verified as the source of truth for all apps.
  3. `package.json` scripts and GitHub workflows reference the correct config.

### Phase 42: Project Status Badges
**Goal**: Add visual status badges to the README to provide immediate feedback on CI/CD status, coverage, and performance.
**Success Criteria**:
  1. `README.md` updated with badges for: Build Status, Test Coverage, Lighthouse Scores, and Bundle Size.
  2. Badges use dynamic links to the latest GitHub Actions runs.
