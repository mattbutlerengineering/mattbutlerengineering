CRITICAL — Sidebar uses native `<a href>`:
The Sidebar component renders `<a href={item.href}>` for items with href.
Inside BrowserRouter, this causes FULL PAGE RELOADS (not client-side nav).
Solution: Use `onClick` + `useNavigate()` instead of `href` on SidebarItems.
