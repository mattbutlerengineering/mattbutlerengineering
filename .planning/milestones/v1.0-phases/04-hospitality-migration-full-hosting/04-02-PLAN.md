<!-- CSS Module + Rialto token pattern. Proven in marketing (Phase 3) and rialto-web (Phase 1). -->

Token reference for CSS Modules:
```css
/* Spacing */
--rialto-space-2xs, --rialto-space-xs, --rialto-space-sm, --rialto-space-md, --rialto-space-lg, --rialto-space-xl, --rialto-space-2xl

/* Typography */
--rialto-text-xs, --rialto-text-sm, --rialto-text-base, --rialto-text-lg, --rialto-text-xl, --rialto-text-2xl

/* Text colors */
--rialto-text-primary, --rialto-text-secondary, --rialto-text-tertiary

/* Surfaces */
--rialto-surface, --rialto-surface-elevated, --rialto-surface-recessed

/* Borders */
--rialto-border, --rialto-border-strong

/* Radius */
--rialto-radius-sharp (2px), --rialto-radius-default (6px), --rialto-radius-soft (10px), --rialto-radius-round (9999px)

/* Weight */
--rialto-weight-normal, --rialto-weight-medium, --rialto-weight-semibold, --rialto-weight-bold
```

CSS logical properties (MANDATORY per Rialto CLAUDE.md):
- padding-inline-start / padding-inline-end (NOT padding-left/right)
- margin-inline-start / margin-inline-end (NOT margin-left/right)
- inset-inline-start / inset-inline-end (NOT left/right for positioned elements)
- padding-block / padding-inline (NOT padding top/bottom + left/right)

Status badge exception:
- Rialto has no semantic status color tokens (pending/confirmed/cancelled)
- Use opaque hex values in CSS Modules for status-specific colors
- Alternatively use Rialto Tag component if appropriate
