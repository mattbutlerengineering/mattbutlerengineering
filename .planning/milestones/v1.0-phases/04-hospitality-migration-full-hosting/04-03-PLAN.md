Token reference for CSS Modules:
```css
/* Spacing: --rialto-space-{2xs|xs|sm|md|lg|xl|2xl|3xl} */
/* Typography: --rialto-text-{xs|sm|base|lg|xl|2xl} */
/* Text colors: --rialto-text-{primary|secondary|tertiary} */
/* Surfaces: --rialto-surface, --rialto-surface-{elevated|recessed} */
/* Borders: --rialto-border, --rialto-border-strong */
/* Radius: --rialto-radius-{sharp|default|soft|round} */
/* Weight: --rialto-weight-{normal|medium|semibold|bold} */
/* Shadows: --rialto-shadow-{sm|md|lg} */
```

CSS logical properties (MANDATORY):
- padding-inline / padding-block (NOT padding-left/right/top/bottom)
- margin-inline / margin-block
- inset-inline-start / inset-inline-end (NOT left/right)
- border-inline-start (NOT border-left)

Common Tailwind → CSS Module mappings:
- bg-white → background: var(--rialto-surface)
- bg-gray-50 → background: var(--rialto-surface-recessed)
- rounded-lg → border-radius: var(--rialto-radius-soft)
- shadow-lg → box-shadow: var(--rialto-shadow-lg)
- p-6 → padding: var(--rialto-space-lg)
- text-gray-500 → color: var(--rialto-text-secondary)
- text-sm → font-size: var(--rialto-text-sm)
- font-medium → font-weight: var(--rialto-weight-medium)
- border border-gray-200 → border: 1px solid var(--rialto-border)

Status/semantic colors (NO Rialto tokens — use hex):
- Green (confirmed/available): #dcfce7 bg, #166534 text
- Yellow (pending): #fef3c7 bg, #92400e text
- Red (cancelled): #fee2e2 bg, #991b1b text
- Blue (selected/active): #dbeafe bg, #1d4ed8 text
</interfaces>
