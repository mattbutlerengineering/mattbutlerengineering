**Append a "Rialto Design System Usage" section to the root `CLAUDE.md` (AIDX-03).**

Add this section BEFORE the "Before Committing" section (which should remain at the end). The section must include:

1. **Import paths:**
   - Components: `import { Button, Input, Card, Text, Stack } from "@mbe/rialto"`
   - Styles: `import "@mbe/rialto/styles"` (must be imported before any component rendering)
   - Motion tokens: `import { spring, precision } from "@mbe/rialto/motion"`

2. **RialtoProvider setup:**
   ```tsx
   import { RialtoProvider } from "@mbe/rialto";
   // Wrap app root:
   <RialtoProvider theme="light"> {/* or "dark" or "system" */}
     <App />
   </RialtoProvider>
   ```

3. **Top 10 most-used component APIs** — brief prop summary for each:
   - Button (variant, size, loading, disabled, onClick)
   - Input (label, hint, error, type, placeholder)
   - Card (variant, padding)
   - Text (variant, size, weight, as)
   - Stack (direction, gap, align, justify)
   - Badge (variant, size)
   - Select (label, options, placeholder, value, onChange)
   - Toggle (label, checked, onChange, disabled)
   - Dialog (open, onClose, title, children)
   - Toast (use via `toast()` function: toast.success(), toast.error())

4. **Token rules (brief):**
   - Never hardcode colors — use `var(--rialto-*)` tokens
   - Spacing: `--rialto-space-{xs|sm|md|lg|xl|2xl|3xl}`
   - Radius: `--rialto-radius-{sharp|default|soft|round}`
   - Always use CSS logical properties (margin-inline-start, not margin-left)

5. **AI reference files:**
   - `llms.txt` — condensed component catalog and token reference (<20KB)
   - `llms-full.txt` — complete prop tables, composition examples, and patterns
   - `packages/rialto/CLAUDE.md` — component authoring guidelines (for contributing to Rialto)
