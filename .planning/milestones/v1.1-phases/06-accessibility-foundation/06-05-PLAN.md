  <action>
Run a grep across all component CSS modules to find which ones already compose `focusRing`:

```bash
grep -rl "focusRing" packages/rialto/src/components/
```

Then cross-reference with the list of all interactive components. For each interactive component that does NOT compose `focusRing`, add it.

The interactive elements that need `focusRing` are any element the user can Tab to:
- Buttons (including close buttons in Dialog/Drawer)
- Form inputs (Input, TextArea, Select, NumberInput, PinInput, Checkbox, Toggle, Slider, Autocomplete)
- Navigation links (Navbar, NavigationMenu, Breadcrumb, Sidebar items)
- Tab triggers (Tabs, SegmentedControl)
- Expandable triggers (Accordion, Collapsible)
- Pagination buttons
- Tree node items
- DropdownMenu/ContextMenu trigger and items
- CommandPalette input
- Tag dismiss button
- Any other focusable element

For each missing component:
1. Open its `.module.css` file
2. Find the class for the interactive element (e.g., `.trigger`, `.item`, `.input`, `.button`)
3. Add `composes: focusRing from "../../styles/surfaces.module.css";` to that class
4. Ensure there's no conflicting `outline` or `:focus` style that would override the focusRing

If a component uses `:focus` instead of `:focus-visible`, change it to `:focus-visible` per user decision. If a component has a custom focus style that conflicts with the gold glow ring, remove the custom style and use `focusRing` instead.

Do NOT add focusRing to non-interactive elements (Card without onClick, Badge without onClick, Text, Stack, Divider, etc.).

Run the full test suite to ensure no visual regressions in tests.
