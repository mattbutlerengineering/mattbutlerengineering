Create `apps/rialto-web/src/pages/examples/` directory and two files:

**ExamplePageLayout.tsx** — export three named components:

1. `ExamplePageLayout` (props: `name: string`, `description: string`, `sourceJsx: string`, `compositionNotes?: ReactNode`, `children: ReactNode`):
   - Renders page header with `Text variant="display" as="h1"` for name, `Text variant="body" color="secondary"` for description
   - Header has a "Copy JSX" `Button variant="secondary" size="sm"` aligned right via `Stack direction="row" align="center" justify="space-between"`
   - Button uses `navigator.clipboard.writeText(sourceJsx)` wrapped in try/catch. On success, button text changes to "Copied!" for 2 seconds via `useState` + `setTimeout`. Add `aria-live="polite"` on the button for screen reader feedback.
   - Below header: `Divider`
   - If `compositionNotes` is provided, render it in a notes container div
   - Then render `children` in a content div

2. `StatePanel` (props: `label: string`, `children: ReactNode`):
   - Renders a container div with a label bar at top using `Text variant="caption" color="tertiary"` showing the label
   - Children render below the label
   - Used for multi-state panels (EXMP-08) — each state is a sibling StatePanel, all visible simultaneously

3. `CompositionNote` (props: `children: ReactNode`):
   - Renders an `<aside className={styles.compositionNote} aria-label="Composition note">`
   - Uses `Text variant="caption" color="secondary"` for the content
   - Always visible (not hidden behind hover/click)

**ExamplePageLayout.module.css** — CSS Module styles:
- `.page` — padding using `var(--rialto-space-xl)`
- `.header` — margin-block-end using `var(--rialto-space-lg)`
- `.notes` — margin-block-start `var(--rialto-space-md)`, padding `var(--rialto-space-md)`, background `var(--rialto-surface-secondary)`, border-radius `var(--rialto-radius-md)`
- `.content` — margin-block-start `var(--rialto-space-xl)`
- `.statePanel` — border `1px solid var(--rialto-border)`, border-radius `var(--rialto-radius-md)`, overflow hidden
- `.statePanelLabel` — padding `var(--rialto-space-xs) var(--rialto-space-sm)`, background `var(--rialto-surface-tertiary)`, border-block-end `1px solid var(--rialto-border)`
- `.statePanelContent` — padding `var(--rialto-space-lg)`
- `.compositionNote` — margin-block-start `var(--rialto-space-sm)`, padding `var(--rialto-space-sm) var(--rialto-space-md)`, border-inline-start `3px solid var(--rialto-accent)`, background `var(--rialto-surface-secondary)`, border-radius `0 var(--rialto-radius-sm) var(--rialto-radius-sm) 0`

All spacing/color values MUST use `var(--rialto-*)` tokens. No hardcoded hex or px values. Use logical properties (margin-block-start, not margin-top; padding-inline, not padding-left).

Import only from `@mbe/rialto`: Text, Button, Stack, Divider.
