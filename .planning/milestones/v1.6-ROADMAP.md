# Roadmap: Milestone v1.6 - Continuous Verification & DevEx

**Milestone Goal:** Elevate developer and agent experience through tighter feedback loops, automated architectural enforcement, and standardized tool interfaces (MCP).

## Phases

### Phase 44: Architectural Enforcement Hook
**Goal**: Add `mbe check-adr` to the pre-commit hook to ensure 100% adherence to architectural decisions.
**Success Criteria**:
  1. `.husky/pre-commit` includes `mbe check-adr`.
  2. Commits containing prohibited patterns (e.g., Tailwind classes) are blocked locally.

### Phase 45: API Contract Regression Testing
**Goal**: Automate verification that service API changes don't break the shared `@mbe/api-client`.
**Success Criteria**:
  1. CI pipeline runs contract tests comparing service schemas against client types.
  2. Schema mismatches block PR merges.

### Phase 46: JIT Context Priming
**Goal**: Automatically run `mbe pack` on relevant directories upon agent session start.
**Success Criteria**:
  1. The agent startup sequence (mandated in `GEMINI.md`) includes JIT packing.
  2. Research latency for new tasks is significantly reduced.

### Phase 47: Dependency Integrity Audit (`mbe check-deps`)
**Goal**: Implement a tool to detect version mismatches and phantom dependencies across the monorepo.
**Success Criteria**:
  1. `mbe check-deps` command identifies conflicting versions of core packages (React, Framer Motion).
  2. Script provides "auto-fix" suggestions or runs `pnpm update`.

### Phase 48: Infrastructure MCP Servers & CLIs
**Goal**: Implement Model Context Protocol (MCP) servers for internal tools to enable deeper agentic integration with infrastructure.
**Success Criteria**:
  1. MCP servers exist for Pulumi, Database, and Auth0.
  2. Agents can query infrastructure state and perform safe management tasks via standardized MCP interfaces.
  3. CLI tools expanded to support these integrations.

### Phase 49: Dependency Synchronization
**Goal**: Fix 17+ dependency version mismatches across the monorepo using pnpm catalogs, centralizing all shared external dependency versions.
**Plans:** 1 plan

Plans:
- [ ] 49-01-PLAN.md -- Migrate 18 deps to pnpm catalog and fix check-deps.ts

**Success Criteria**:
  1. `mbe check-deps` exits 0 with no version mismatches.
  2. All shared external dependencies use `catalog:` protocol in package.json files.
  3. Full CI suite (lint + typecheck + test) passes after migration.
