Create `packages/rialto-catalog/scripts/generate-catalog.ts` by extending the pattern from `packages/rialto/scripts/generate-manifest.ts`. This script reads Rialto component prop interfaces via the TypeScript Compiler API and outputs Zod schema definitions to `src/generated-schemas.ts`.

Key implementation details:

1. Reuse the same extraction pattern from generate-manifest.ts: `ts.createProgram()` with the entry file at `packages/rialto/src/components/index.ts` (resolve path relative to the script). Use `checker.getExportsOfModule()`, iterate exports, find `ComponentNameProps` interface, then `propsType.getProperties()`.

2. Curated filter: Only include the 26 components listed in catalog-config.ts. All others are skipped. The curated list: Stack, Card, Divider, AspectRatio, Text, Badge, Avatar, Button, Input, Select, Toggle, Checkbox, Tabs, Breadcrumb, NavigationMenu, Alert, Banner, Dialog, Toast, Table, DataList, EmptyState, Accordion, Sidebar, AppBar, Footer.

3. Type string to Zod schema mapping:
   - Union of string literals ("primary" | "secondary" | "ghost") -> `z.enum(["primary", "secondary", "ghost"])`
   - `boolean` or `true | false` -> `z.boolean()`
   - `number` -> `z.number()`
   - `string` -> `z.string()`
   - Optional props -> append `.optional()`
   - Skip function types (event handlers like onClick, onChange, onCheckedChange)
   - Skip ReactNode props (these become slots, not Zod schemas)
   - Skip complex object types and array-of-objects types. Log a warning for unrecognized patterns.

4. Character limits: Import characterLimits from `../../rialto/scripts/character-limits.ts` (use path.resolve). For each z.string() schema where a matching character limit exists (by component name + prop name), append `.max(n)`. Example: Card.title has max=60 -> output `z.string().max(60).optional()`.

5. Output format: Write a TypeScript file `src/generated-schemas.ts` with:
   ```
   // AUTO-GENERATED -- do not edit. Run: pnpm --filter @mbe/rialto-catalog generate
   import { z } from "zod";

   export const generatedSchemas = { ... } as const;
   ```
   Sort component names alphabetically for deterministic output. Do NOT include generatedAt timestamps or anything non-deterministic.

6. Add "generate" script to package.json: `"generate": "tsx scripts/generate-catalog.ts"`.

7. Run the generator and commit the initial generated-schemas.ts.

What to avoid and WHY:
- Do NOT hand-write any Zod schemas. They drift from Rialto source immediately.
- Do NOT include non-deterministic output (timestamps). Breaks CI drift check.
- Do NOT try to handle every TypeScript type pattern. Start with the types that actually appear in the 26 curated components' props. Log warnings for unrecognized patterns.
