  prompt     String
  spec       Json

  isFavorite Boolean  @default(false) @map("is_favorite")

**Service layer** (`services/agent/src/services/stored-spec.ts`):
Create `storedSpecService` object following the session.ts pattern. Import `prisma` from `./database.js`. Import `StoredSpec` type from `../generated/prisma/index.js`.

Methods:
- `list(userId: string)`: findMany where userId, orderBy createdAt desc, take 100. Returns StoredSpec[].
- `getById(id: string)`: findUnique where id. Returns StoredSpec | null.
- `create(data: { userId, prompt, spec, rawLines })`: Calls `_enforceCapForUser` first, then prisma.storedSpec.create. Cast spec as `Prisma.InputJsonValue`. Returns StoredSpec.
- `toggleFavorite(id: string, userId: string)`: findUnique, check userId matches (throw Error("Not found") if not), update isFavorite to !existing.isFavorite. Returns StoredSpec.
- `delete(id: string, userId: string)`: findUnique, check userId matches (throw Error("Not found") if not), delete. Returns void.
- `_enforceCapForUser(userId: string)`: Count unfavorited specs for user. If >= 100, find oldest unfavorited (orderBy createdAt asc), delete it.

Create a `mapStoredSpec` helper function that converts Prisma StoredSpec to a plain API response object with camelCase fields and ISO string dates (matching the mapPrismaSession pattern in session.ts). All route handlers use this mapper before sending responses.

**Routes** (`services/agent/src/routes/gen-specs.ts`):
Export `genSpecsRoutes` as FastifyPluginAsync. Five routes:

1. `POST /api/gen/specs` — preHandler: [requireAuth]. Validate body with Zod: { prompt: string, spec: unknown, rawLines: string[] }. Call storedSpecService.create with request.user.id. Return 201 with { data: mapStoredSpec(result) }.

2. `GET /api/gen/specs` — preHandler: [requireAuth]. Call storedSpecService.list(request.user.id). Return 200 with { data: results.map(mapStoredSpec) }.

3. `GET /api/gen/specs/:id` — NO preHandler (public for permalink). Call storedSpecService.getById. If null, return 404 { error: "Not Found", message: "Spec not found", statusCode: 404 }. Return 200 { data: mapStoredSpec(result) }.

4. `PATCH /api/gen/specs/:id/favorite` — preHandler: [requireAuth]. Call storedSpecService.toggleFavorite with request.user.id. Catch "Not found" errors and return 404. Return 200 { data: mapStoredSpec(result) }.

5. `DELETE /api/gen/specs/:id` — preHandler: [requireAuth]. Call storedSpecService.delete with request.user.id. Catch "Not found" errors and return 404. Return 204.

Add a comment on the public GET: `// PUBLIC — no auth required for permalink viewing`

**Register in app.ts**: Import genSpecsRoutes and add `await fastify.register(genSpecsRoutes);` after the genChatRoutes registration line.

**Tests** (`services/agent/src/routes/gen-specs.test.ts`):
Follow existing test patterns in the agent service. Mock `../services/stored-spec.js` with vi.mock. Use app.inject() for each endpoint.

Test cases:
- POST /api/gen/specs: returns 201 with saved spec
- GET /api/gen/specs: returns 200 with array of specs
- GET /api/gen/specs/:id: returns 200 for existing, 404 for missing
- GET /api/gen/specs/:id: works WITHOUT auth header (public)

- DELETE /api/gen/specs/:id: returns 204
- DELETE /api/gen/specs/:id: returns 404 for wrong user

Use consistent error response format: `{ error: string, message: string, statusCode: number }`.
