   - Import `catalog` from `"@mbe/rialto-catalog"`
   - Import `z` from `"zod"`
   - Memoize `catalog.prompt()` at module level: `const SYSTEM_PROMPT = catalog.prompt();`
   - Define `GenUiBodySchema = z.object({ prompt: z.string().min(1).max(2000), model: z.enum(["haiku", "sonnet"]).optional().default("haiku") })`
   - Define `MODEL_IDS = { haiku: "anthropic/claude-haiku-4.5", sonnet: "anthropic/claude-sonnet-4.6" } as const`
   - Export `genUiRoutes: FastifyPluginAsync` that registers `POST /api/gen/ui`:
     - `preHandler: [requireAuth]` (GEN-03)
     - Validate body with `GenUiBodySchema.safeParse()`, return 400 on invalid
     - Call `streamText({ model: MODEL_IDS[modelHint], messages: [{ role: "system", content: SYSTEM_PROMPT, providerOptions: { anthropic: { cacheControl: { type: "ephemeral" } } } }, { role: "user", content: prompt }], output: Output.object({ schema: z.object({ spec: z.any() }) }), onFinish: ... })` (GEN-05, GEN-08)
     - In `onFinish`, log `userId`, `modelId`, `promptTokens`, `completionTokens`, `cacheReadInputTokens`, `cacheCreationInputTokens` via `request.log.info()` (GEN-06)
     - Set SSE headers: `Content-Type: text/plain; charset=utf-8`, `Cache-Control: no-cache`, `Connection: keep-alive`, `x-vercel-ai-ui-message-stream: v1`, `X-Accel-Buffering: no`
     - Return `reply.send(result.toUIMessageStream())` (GEN-01)
   - Follow the exact pattern from 13-RESEARCH.md "Complete gen-ui.ts Route Handler" code example
   - CRITICAL: Use `messages` array with `role: "system"` (NOT the top-level `system:` string param) — only the messages array supports `providerOptions` for cache control breakpoints

4. Create `services/agent/src/routes/gen-chat.ts`:
   - Same imports as gen-ui except no `Output` import needed
   - Memoize `SYSTEM_PROMPT` at module level
   - Define `GenChatBodySchema = z.object({ messages: z.array(z.object({ role: z.enum(["user", "assistant"]), content: z.string() })) })`
   - Export `genChatRoutes: FastifyPluginAsync` that registers `POST /api/gen/chat`:
     - `preHandler: [requireAuth]` (GEN-03)
     - Validate body with `GenChatBodySchema.safeParse()`, return 400 on invalid
     - Call `streamText({ model: "anthropic/claude-haiku-4.5", messages: [{ role: "system", content: SYSTEM_PROMPT, providerOptions: { anthropic: { cacheControl: { type: "ephemeral" } } } }, ...parsedMessages] })`
     - Same `onFinish` cost logging pattern (GEN-06)
     - Same SSE headers
     - Return `reply.send(result.toUIMessageStream())` (GEN-02)
