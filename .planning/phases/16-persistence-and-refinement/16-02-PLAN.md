**useSpecsApi.ts** (`apps/gen/src/hooks/useSpecsApi.ts`): New file. Custom hook that manages specs CRUD with loading/error state.

- Import `useAuth` from `@mbe/auth/react` to get `accessToken`.
- Create a `authFetch` helper wrapped in `useCallback([accessToken])` that adds Authorization header and Content-Type: application/json.
- State: `specs: StoredSpec[]`, `isLoading: boolean`.
- `fetchSpecs()`: GET /api/gen/specs, set specs from response.data, set isLoading false. Wrapped in useCallback depending on authFetch.
- `saveSpec(data: { prompt, spec, rawLines })`: POST /api/gen/specs, then prepend the returned spec to the local specs array (immutable update). Returns the created StoredSpec.
- `toggleFavorite(id: string)`: Optimistic update — immediately flip isFavorite in local state via setSpecs(prev => prev.map(...)), then PATCH /api/gen/specs/:id/favorite. On error, revert the optimistic update.
- `deleteSpec(id: string)`: Optimistic removal from local state, then DELETE /api/gen/specs/:id. On error, revert.
- `useEffect(() => { void fetchSpecs(); }, [fetchSpecs])` to load on mount.
- Return: `{ specs, isLoading, fetchSpecs, saveSpec, toggleFavorite, deleteSpec }`.

**useGenStream.ts**: Extend the `onComplete` callback signature to pass rawLines as second argument:
- Change `onComplete?: (spec: Spec) => void` to `onComplete?: (spec: Spec, rawLines: string[]) => void`
- In the send function, where `onCompleteRef.current?.(finalSpec)` is called, change to `onCompleteRef.current?.(finalSpec, accumulatedRawLines)` where `accumulatedRawLines` is collected from the locally accumulated lines inside the stream loop (NOT from React state which may be stale). Track raw lines in a local array `const accumulatedRawLines: string[] = []` alongside `accumulatedElements`, pushing each trimmed line.

This avoids the stale closure pitfall documented in RESEARCH.md — rawLines come from the local variable inside send(), not from React state.
