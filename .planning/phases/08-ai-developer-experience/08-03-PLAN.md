Create `tools/cli/src/commands/new.ts` using the commander pattern from `agent.ts`.

**Command definition:**
```typescript
export const newCommand = new Command("new")
  .alias("init")
  .description("Scaffold a new app with Rialto provider and example page")
  .argument("<name>", "App name in kebab-case (creates apps/<name>/)")
  .option("-p, --port <port>", "Dev server port (default: auto-detect next available)")
  .action(async (name: string, options: { port?: string }) => { ... });
```

**Validation:**
- Validate `name` is kebab-case (lowercase letters, numbers, hyphens only): `/^[a-z][a-z0-9-]*$/`
- Check `apps/<name>/` does not already exist — error if it does
- Resolve the monorepo root by walking up from `process.cwd()` looking for `pnpm-workspace.yaml`, or default to `process.cwd()`

**Port auto-detection:**
- If `--port` is not provided, scan all `apps/*/vite.config.ts` files for `port:` values using a simple regex (`/port:\s*(\d+)/`). Also include known ports from CLAUDE.md (3000-3004). Find the max and add 1. Default to 3005 if no configs found.
- If `--port` IS provided, use that value.
