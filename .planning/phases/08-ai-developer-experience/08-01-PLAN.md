1. **Output path:** Write to `packages/rialto/registry.json` (package root, NOT `dist/`). The `dist/` directory is gitignored; `registry.json` at package root is not (no `.gitignore` exists in `packages/rialto/`).

2. **Registry interface:** Extend ComponentInfo with `importPath` field (always `"@mbe/rialto"` since all components are barrel-exported):

```typescript
interface RegistryComponent {
  name: string;
  description?: string;
  importPath: string;      // always "@mbe/rialto"
  props: PropInfo[];
  slots: string[];
  characterLimits?: CharacterLimitInfo[];
}

interface Registry {
  version: string;
  generatedAt: string;
  components: RegistryComponent[];
}
```

3. **Reuse extraction logic:** Import and call the same `extractComponents` function pattern from `generate-manifest.ts`. Do NOT import from generate-manifest.ts directly (it runs as a standalone script with `main()`). Instead, copy the extraction logic into generate-registry.ts or extract shared helpers into a shared module. The simplest approach: copy the extraction functions (`getJsDocComment`, `typeToString`, `getDefaultFromInitializer`, `extractComponents`) into generate-registry.ts and add the `importPath` field during the map step.

4. **Character limits:** Import `characterLimits` from `./character-limits.js` and merge into components, same as generate-manifest.ts does.

5. **Output:** `JSON.stringify(registry, null, 2) + "\n"` to `packages/rialto/registry.json`.

1. Add a `prebuild` script to `apps/rialto-web/package.json` that copies registry.json into the public directory:
```json

"build": "tsc && vite build"
```
The `prebuild` hook runs automatically before `build`. Cloudflare Pages serves `.json` files from `public/` with `application/json` Content-Type automatically.

2. Copy `packages/rialto/registry.json` to `apps/rialto-web/public/registry.json` now so it exists for dev/build. This file should be in `.gitignore` for rialto-web since it's a build artifact copied from the source of truth in `packages/rialto/`. Add `public/registry.json` to `apps/rialto-web/.gitignore` (create the file if it does not exist).

**CI drift check (AIDX-01 success criterion):**

3. Add a new step to the `build` job in `.github/workflows/ci.yml`, AFTER the "Build all packages" step:
```yaml
- name: Check registry.json is up to date
  run: |
    pnpm --filter @mbe/rialto build:registry
    git diff --exit-code packages/rialto/registry.json || \
      (echo "ERROR: registry.json is stale. Run 'pnpm --filter @mbe/rialto build:registry' locally and commit the result." && exit 1)
```

This uses `git diff --exit-code` which returns non-zero if the file changed — same pattern used for Prisma migration status checks in this repo.
