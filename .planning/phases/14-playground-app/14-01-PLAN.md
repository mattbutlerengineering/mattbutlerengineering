  <action>
Create `useGenStream` — a custom hook that mirrors the `UseUIStreamReturn` interface from `@json-render/react` but injects the Auth0 Bearer token into the fetch request.

**Why not use `useUIStream` directly:** The hook does a plain `fetch()` with no auth header customization (confirmed by reading the source in node_modules). The backend requires JWT auth (GEN-03), so the token MUST be in the Authorization header.

**Implementation:**
1. Import `useAuth` from `@mbe/auth/react` to get `accessToken`
2. Import `Spec` from `@json-render/react` and `buildSpecFromParts` + `flatToTree` if needed for spec assembly
3. Manage state: `spec` (Spec | null), `isStreaming` (boolean), `error` (Error | null), `usage` (TokenUsage | null), `rawLines` (string[])
4. Store `AbortController` in a ref for abort/stop support
5. `send(prompt, context?)` function:
   - Abort any in-flight request
   - Create new AbortController
   - Reset state (isStreaming=true, error=null, rawLines=[])
   - `fetch(api, { method: "POST", headers: { "Content-Type": "application/json", "Authorization": "Bearer " + accessToken }, body: JSON.stringify({ prompt, context }), signal })`
   - If response is not ok, throw with response status text
   - Read the response body as a ReadableStream using `getReader()` + `TextDecoder`
   - Parse each line as JSONL: accumulate rawLines, parse JSON patches, build spec progressively
   - For spec assembly: each JSONL line is a JSON patch. Parse each line, check for `type: "usage"` (extract TokenUsage), otherwise treat as a spec element. Use `flatToTree()` from `@json-render/react` to convert accumulated flat elements to a Spec.
   - On stream complete: call `onComplete?.(spec)`, set `isStreaming=false`
   - On error: set error, call `onError?.(error)`, set `isStreaming=false`
   - On abort (AbortError): keep whatever spec has been built, set `isStreaming=false` (no error)
6. `clear()` function: reset spec, error, rawLines to initial state
7. Return `{ spec, isStreaming, error, usage, rawLines, send, clear }`

**CRITICAL detail on JSONL parsing:** The agent service at `/api/gen/ui` streams newline-delimited JSON. Each line is either:
- A flat element: `{ "key": "...", "type": "...", "props": {...}, "parentKey": "..." }`
- A usage line: `{ "type": "usage", "promptTokens": N, "completionTokens": N, "totalTokens": N }`

Accumulate flat elements into an array. After each new element, call `flatToTree(elements)` to produce the live `Spec`. This matches the progressive rendering behavior of `useUIStream`.

**Hook signature:**
```typescript
interface UseGenStreamOptions {
  api: string;
  onComplete?: (spec: Spec) => void;
  onError?: (error: Error) => void;
}

export function useGenStream(options: UseGenStreamOptions): UseUIStreamReturn;
```

Use stable refs for callbacks (onComplete, onError) to avoid re-creating the send function on every render — same pattern as useUIStream source.
