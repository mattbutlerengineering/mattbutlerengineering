    This is the standard page wrapper that every component page uses. It provides consistent structure per the locked decisions: variants, states, examples, playground, props table, accessibility.

    - Page title (component name) as `<Text size="2xl" weight="medium">`

    ```typescript

        <div className={styles.section}>

          <div className={styles.sectionContent}>{children}</div>
        </div>
      );
    }
    ```

    For each component, create a "Playground" section with state-driven controls:
    ```tsx
    function ButtonPlayground() {
      const [variant, setVariant] = useState<"primary" | "secondary" | "ghost">("primary");
      const [size, setSize] = useState<"sm" | "md" | "lg">("md");
      const [disabled, setDisabled] = useState(false);
      const [loading, setLoading] = useState(false);

      return (
        <Stack gap="lg">
          {/* Live preview */}
          <Card>
            <Button variant={variant} size={size} disabled={disabled} loading={loading}>
              Button Label
            </Button>
          </Card>
          {/* Controls */}
          <Stack direction="horizontal" gap="md" wrap>
            <Select label="Variant" value={variant} onChange={setVariant} options={[...]} />
            <Select label="Size" value={size} onChange={setSize} options={[...]} />
            <Checkbox label="Disabled" checked={disabled} onChange={setDisabled} />
            <Checkbox label="Loading" checked={loading} onChange={setLoading} />
          </Stack>
        </Stack>
      );
    }
    ```

    Use Rialto's own form components (Select, Checkbox, Toggle, Input) as the playground controls. This is another "eat your own cooking" win.
