**RadialGauge — removed.** The `RadialGauge` analog dial has been removed from the design system. For bounded 0–100 metrics use `Meter`, which exposes the same `role="meter"` accessible contract (value / min / max, visible readout, and label). The `@mattbutlerengineering/rialto/RadialGauge` subpath export, the catalog entry, and the `/components/radial-gauge` showcase page are gone.
