Three accessibility fixes. ImageUpload: the empty tile is named from its visible "Add image" text (plus the label), the error overlay renders outside the tile, and the preview tile is no longer a `role="button"` wrapping the Replace button. Because the tile is now named from `addImage`, the `uploadImage` message key is removed from `RialtoMessages` and the built-in locales; a locale object that still sets `uploadImage` now fails typecheck with an excess-property error, so delete that line. Dialog takes a `role` prop (`"dialog"` | `"alertdialog"`), and a destructive ConfirmDialog is now `role="alertdialog"` (the default variant stays `dialog`); a generated Dialog forwards `role` too. Form: an error the Form's assertive summary already carries is no longer announced a second time by its field, so one error is announced once and stays visible and linked through `aria-describedby`. A field error the summary does not carry (set by the server, raised on blur, or after a valid submit), a field used outside a Form, and every field in a Form with `showErrorSummary={false}` still announce their own error.
